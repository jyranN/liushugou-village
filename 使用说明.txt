柳树沟村 · 数字村落（甘肃岷县风格 3D 虚拟村庄）
============================================================

一、最快打开方式
------------------------------------------------------------
双击「柳树沟村.html」即可。
不需要联网、不需要服务器、不需要安装任何东西。
推荐 Chrome / Edge / Safari 最新版；仅支持桌面端（鼠标 + 键盘）。


二、这是什么
------------------------------------------------------------
一个虚构村落「柳树沟村」的三维数字孪生演示：
· 14 座民居、95 棵树、16 头家畜、14 块耕地、13 处公共设施、9 件院落物件，
  另有 5 只村口石墩、1 座石碾、3 处水窖，共 170 个可点对象
· 每栋房、每棵树、每头牲畜、每块地、每只石墩都有独立档案卡
· 村西有河（水磨坊临河、漫水桥），村东有山（山腰山神庙、40 级石阶）
· 时间由甘肃岷县 2025 年全年 8760 小时真实气象数据驱动
· 昼夜、季节、雨雪连续变化：太阳位置按天文公式逐帧解算
· 画质三档（流畅/均衡/精致）、天气四预设（晴/阴/雨/雪）、自动巡游


三、操作
------------------------------------------------------------
【上帝视角】
  左键拖拽        绕村旋转
  滚轮 / 双指     缩放
  点击物体        弹出档案卡，点空白处关闭
  复位            回到默认机位

【第一人称】
  F 或「第一人称」按钮   进入；Esc 退出
  W A S D / 方向键       前后左右
  按住左键拖动           转头
  Shift                  加速

【时间与天气】
  底部时间条      直接拖动，一格 15 分钟
  播放 / 暂停     按钮，或按空格
  时间流速        右侧「一天 6分 / 3分 / 1分 / 20秒」，默认 3 分钟
  天气预设        晴 / 阴 / 雨 / 雪，跳到 2025 年实测对应时刻

【画质与巡游】
  画质            右下角「流畅 / 均衡 / 精致」，选择会记住
  巡游            右下角「巡游」，6 个镜头约 32 秒
  中断巡游        Esc 或点画面任意处

五、二次开发
------------------------------------------------------------
需要 Node 18+。

  重新打包单文件版：
    cd 源码
    npm install
    node tools/build-standalone.mjs

  本地调试：
    cd 源码
    npx serve .            # 或 python3 -m http.server 8099
    打开 http://localhost:8099/index.html

  重新生成文档：
    python3 tools/md2docx.py ../文档/源稿/01-管理员手册.md /tmp/test.docx \
        --kind 管理员手册 --docno DOC-01

  调试参数（加在 URL 后面）：
    ?day=131&hour=10        指定日期与小时
    ?pause=1                打开时暂停
    ?speed=0..3             起始速度档
    ?tx=0&tz=40&r=60&phi=1.3&theta=1.57    指定机位
    ?quality=low|mid|high   临时指定画质档
    ?ao=1                   强制打开 GTAO
    ?nopost=1               关全部后处理
    ?fixedscale=1           关闭自适应分辨率
    ?qa=1                   显示自检面板

七、已知限制
------------------------------------------------------------
· 仅桌面端，未做触屏适配
· 首次打开需 3~6 秒生成地形与材质
· 集显机器会自动降低渲染分辨率以保证帧率（右上角显示实时 FPS）
· 村落、住户、牲畜等全部为虚构数据，仅用于演示
· 没有村民角色，只有牲畜
· 没有电线杆与架空线（早期原型有过一版，未进入现行代码）
