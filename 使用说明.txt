柳树沟村 · 数字村落（甘肃岷县风格 3D 虚拟村庄）
============================================================

一、最快打开方式
------------------------------------------------------------
双击「柳树沟村.html」即可。
不需要联网、不需要服务器、不需要安装任何东西。
推荐 Chrome / Edge / Safari 最新版；仅支持桌面端（鼠标 + 键盘）。


二、这是什么
------------------------------------------------------------
一个虚构村落「柳树沟村」的三维数字孪生演示：
· 14 座民居、101 棵树、16 头家畜、14 块耕地、13 处公共设施、9 件院落物件，
  另有 5 只村口石墩、1 座石碾、3 处水窖、村口广场与村委会的 2 面村旗，
  以及 6 处院外共享场院里的 16 件生产性空间物件、村中心 4 处新建公共场所，
  共 198 个可点对象
· 生产性空间六类：麦场（压实土圆场带边石）、草垛、柴垛、粪堆、鸡窝、猪圈；
  每 2~3 户共用一处场院，放在院外背街一侧，避让主路与耕地
· 道路分三层：水泥主路（6.2m + 两侧 0.45m 路肩）、土质巷道（5 条）、
  田埂小路（11 条 576.5m）；三类合批成 1 个 Mesh，draw call 不增反降
· 作物物候五状态（休耕/出苗/生长/成熟/收割后留茬），由逐小时气温累积的有效积温驱动；
  8 种作物分四族形态（玉米高秆、小麦密植、马铃薯低矮、当归带伞形花序）
· 地形三层材质：按坡度、高度、曲率混合草 / 土 / 石三层 PBR，三个平铺周期互不成
  整数比，近景再叠一层第二尺度打散重复；山体能读出裸岩层次，draw call 增量为 0
· 公共核心：既有村委会原址补村务公示栏（档案卡另写明全村 43 人 / 耕地 513 亩），
  再新建小卖部（手写感招牌）、卫生室（白底红十字）、戏台（青瓦顶「同乐台」）、
  文化广场（水泥场坪、石桌凳）；主路两侧分开落位，不挤在一处、不挡主路视线
· 每栋房、每棵树、每头牲畜、每块地、每只石墩、每处场院物件都有独立档案卡
  （民居卡另有户主、耕地亩数、牲畜数量、主要作物、年收入估算）
· 村西有河（水磨坊临河、漫水桥），村东有山（山腰山神庙、40 级石阶）
· 时间由甘肃岷县 2025 年全年 8760 小时真实气象数据驱动
· 昼夜、季节、雨雪连续变化：太阳位置按天文公式逐帧解算
· 风看得见：岷县实测风速风向驱动两面旗、草地作物摆动与雨雪倾斜
· 屋顶炊烟：早/中/晚三个饭点按作息升起，受真实风向风速影响
· 画质三档（流畅/均衡/精致）、天气四预设（晴/阴/雨/雪）、自动巡游
  （6 段约 37 秒；第 2 段进村时缓缓抬升，越过院墙带你看公共核心）
· 同机位对比：点「对比」记下当前画面为 A，改时间看 B，滑杆分屏 / 按住 Tab 闪回


三、操作
------------------------------------------------------------
【上帝视角】
  左键拖拽        绕村旋转
  滚轮 / 双指     缩放
  点击物体        弹出档案卡，点空白处关闭
  复位            回到默认机位

【第一人称】
  F 或「第一人称」按钮   进入；Esc 退出
  W A S D / 方向键       前后左右
  按住左键拖动           转头
  Shift                  加速

【时间与天气】
  底部时间条      直接拖动，一格 15 分钟
  播放 / 暂停     按钮，或按空格
  时间流速        右侧「一天 6分 / 3分 / 1分 / 20秒」，默认 3 分钟
  天气预设        晴 / 阴 / 雨 / 雪，跳到 2025 年实测对应时刻

【画质与巡游】
  画质            右下角「流畅 / 均衡 / 精致」，选择会记住
  巡游            右下角「巡游」，6 个镜头约 32 秒
  中断巡游        Esc 或点画面任意处

五、二次开发
------------------------------------------------------------
需要 Node 18+。

  跑一次数据与落位校验：
    node tools/verify-cards.mjs         # 民居卡数字、村委会全村口径 vs 场景实例
    node tools/verify-production.mjs    # 场院避让道路、耕地、院墙与杆脚
    node tools/verify-civic.mjs         # 公共核心落位、巡游镜头与 43 人 / 513 亩口径
    node tools/verify-terrain.mjs       # 地形三层权重归一、三个周期比、三档 LOD
    node tools/verify-crop.mjs          # 地块作物、积温自洽、五状态连续性
    node tools/verify-road.mjs          # 三类路面宽度、净空、不交叉、单 Mesh
    node tools/verify-tree.mjs          # 四种树形、区位分配比例、可复现
    node tools/verify-scrub.mjs         # 野性层常量、draw call 预算、季节接线
    node tools/verify-livestock.mjs     # 牲畜计数、微动作常量、避檐与暂停口径
    node tools/verify-farm.mjs          # 地膜/篱笆/田埂口径、合并与防 z-fighting
    node tools/verify-climate-chart.mjs # 气象面板：自绘、降采样、双向同步、按需重绘
    node tools/verify-teach.mjs         # 标注层/剖面：图集、裁剪还原、数值口径、互斥
    node tools/verify-civic.mjs --self-test   # 负向自测：把 C-01 挪进主路应报错

  重新打包单文件版：
    cd 源码
    npm install
    node tools/build-standalone.mjs

  本地调试：
    cd 源码
    npx serve .            # 或 python3 -m http.server 8099
    打开 http://localhost:8099/index.html

  重新生成文档：
    python3 tools/md2docx.py ../文档/源稿/01-管理员手册.md /tmp/test.docx \
        --kind 管理员手册 --docno DOC-01

  调试参数（加在 URL 后面）：
    ?day=131&hour=10        指定日期与小时
    ?pause=1                打开时暂停
    ?speed=0..3             起始速度档
    ?tx=0&tz=40&r=60&phi=1.3&theta=1.57    指定机位
    ?quality=low|mid|high   临时指定画质档
    ?ao=1                   强制打开 GTAO
    ?nopost=1               关全部后处理
    ?fixedscale=1           关闭自适应分辨率
    ?qa=1                   显示自检面板（含 pickables 198、production 16 个 / 6 处场院 / 4 组合批 Mesh、civic 4 处新建 / 5 处公共场所 / 5 组合批 Mesh、terrain 3 层 草 2.07m / 土 4.50m / 石 26.00m、crops 株数 / 5 族 / 状态分布、
                          roads 3 类 / 1 合批 Mesh）
    ?quality=low&scale=0.75 验收统一口径：流畅档 + 固定 0.75 像素比

七、已知限制
------------------------------------------------------------
· 仅桌面端，未做触屏适配
· 首次打开需 3~6 秒生成地形与材质
· 集显机器会自动降低渲染分辨率以保证帧率（右上角显示实时 FPS）
· 村落、住户、牲畜等全部为虚构数据，仅用于演示
· 没有村民角色，只有牲畜
· 主路沿线已有 8 根水泥电线杆与简化架空线，但不做碰撞，也未单独出验收记录
· 公共核心四处建筑是静态陈设（参与第一人称碰撞，但不随时间轴或天气变化）
· 路面是纯视觉层，不参与拾取、不做碰撞；田埂只铺在田区，不与村内巷道物理连通
· 地形三层的细节层（草层第二尺度、三层法线、三层粗糙度）只在近景叠，
  低/中/高档分别是 30/36/44 m 内；远景保留三层颜色但退回单层法线与粗糙度
