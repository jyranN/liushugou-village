1. **村西河与漫水桥**：新增近南北向小河、临河水磨坊与可踏上的漫水桥，河滩地退到东岸。

3. **自动巡游与画质/天气入口**：新增 6 段约 33 秒的自动巡游、流畅/均衡/精致三档画质、晴/阴/雨/雪四个实测天气预设。

> 完整变更见包内 `CHANGELOG.md`（体验 / 性能 / 内容 / 交付 / 修复 五段）；验证记录见包内 `文档/发布验证-v1.1.md`。

## 下载后怎么用

1. 下载 `Liushugou-Village-1.1.zip`。
2. 解压到任意目录（不要只解压出 HTML 一个文件）。
3. 双击 `柳树沟村.html`，用 Chrome / Edge / Safari 打开；不需要联网，不需要本地服务器。
4. `F` 进第一人称，`Esc` 退出；右下角「巡游」自动运镜，「画质」切三档；底部时间条可拖，右侧「晴/阴/雨/雪」跳到 2025 年实测时刻。
5. 包根 `MANIFEST.txt` 列出全部文件与逐文件 SHA-256；在包根执行 `shasum -a 256 -c MANIFEST.sha256` 可校验完整性。
