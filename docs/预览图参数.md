# 预览图参数与校验

本文件记录 `preview-01` ~ `preview-08` 八张预览图的**固定拍摄参数**与文件校验值，便于复现和核对。

## 统一参数

| 项 | 取值 |
|---|---|
| 分辨率 | 1600 × 900 |
| 格式 | PNG（截图后不再压缩） |
| 画质档 | `?quality=high`（GTAO 开、泛光开、阴影 3072²） |
| 像素比 | `?fixedscale=1&scale=1`（固定 1.0，不走自适应） |
| 时间 | `?pause=1`，按表中 `day/hour` 固定；不使用随机天气 |
| 相机 | 上帝视角按球坐标反算；第一人称站定、眼高 1.68 米 |
| 界面 | 截图前隐藏 `#hud`，保留纯画面 |
| 等待 | 页面就绪后 4.2 秒，相机到位后 2.2 秒再截 |

## 说明

- **晴**：天气预设按钮指向 2025-07-30 15:00；预览图取同一天 10:00（云量也是 0%），上午侧光更能看出墙体与树的体积。
- **雨**：预设按钮指向全年降水最大的 2025-09-05 02:00，那是夜间。为了让人看清雨丝与湿路面，预览改用**全年白天降水最大**的 2025-07-25 15:00（6.5 mm/h），仍是固定实测时刻，不是随机天气。
- **雪**：直接用预设时刻 2025-03-05 11:00，积雪覆盖 0.813，地面与屋顶可见积雪。
- 所有图片均由同一份源码（v1.1 工作树）在无头 Edge 中截取；截图后代码只改了文档与打包脚本，渲染代码未再改动。
