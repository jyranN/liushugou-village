## 文档说明

**管理员手册**讲怎么用：运行环境、启动方式、界面导览、两种视角的操作、演示脚本、性能调节、故障排查、内容维护、合规说明。

**项目手册**讲是什么、怎么做的：需求与实现对照、系统架构、关键技术（连续太阳解算、真实气象驱动、实例化植被、后处理链）、内容设计、性能设计与局限。

**项目目录**讲东西在哪：交付包结构、目录职责、源码文件表、数据字段表、素材与依赖清单、构建产物构成、编号与命名规范、体积统计。

**项目日志**讲怎么走到今天的：十九个阶段的时间线（含 v1.1 的九轮增补）、每个阶段踩的坑与修法、36 条问题台账、遗留待办、版本记录。

## 重新生成

四份文档由 Markdown 源稿生成，改完源稿后执行：

```bash
cd village
python3 tools/md2docx.py docs/src/01-管理员手册.md docs/01-管理员手册.docx \
    --kind 管理员手册 --docno DOC-01
```

其余三份换文件名与 `--kind` 即可。生成过程会调用 WorkBuddy 的 HTML→DOCX 转换器，自动生成封面、目录域（可点击跳转）、页码与章节分页。

> 含 `&` 的文档（管理员手册、项目手册）加 `--fast` 跳过内容校验：转换器会把 `&` 正确写成 `&amp;`，但校验脚本会把它误判为丢段。
