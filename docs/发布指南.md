# 发布指南

项目已经是一个完整的 git 仓库：`main` 分支、两次提交、标签 `v1.0`。现在缺的只是「第一次把仓库放到 GitHub 上」这一步授权，之后每一版都可以按下面的流程走。

## 一、第一次发布到 GitHub（VS Code，约 1 分钟）

1. 打开 VS Code（已停在 `三维村落` 目录）。
2. 左侧点**源代码管理**图标（分支形状，快捷键 `Ctrl+Shift+G`）。
3. 点蓝色的 **Publish Branch**（中文界面为「发布分支」）。
4. 选择 **Publish to GitHub public repository**（公开仓库）。
5. 仓库名填 **`liushugou-village`**（不要用默认的中文目录名），回车。

如果弹出 GitHub 登录，按提示在浏览器授权一次即可。完成后仓库地址是：

```
https://github.com/<你的用户名>/liushugou-village
```

> 命令行没有配置任何 GitHub 凭据，所以这一步必须在 VS Code 里做一次；做完之后远程仓库就已经绑定好了。

## 二、上传这一版的安装包

仓库里不放 15 MB 的 HTML 和 21 MB 的 zip（会让仓库越来越臃肿），它们放在 **Releases** 里：

1. 打开仓库页面 → 右侧 **Releases** → **Draft a new release**。
2. Tag 选 **`v1.0`**，标题填 `v1.0`。
3. 把 `dist/Liushugou-Village-1.0.zip` 拖进附件框。
4. 点 **Publish release**。

README 里已经写了「到 Releases 下载」，下载的人双击就能看。

## 三、以后每一版怎么发

### 方式 A：装了 GitHub CLI（推荐，一条命令）

```bash
brew install gh
gh auth login          # 选 GitHub.com → HTTPS → 浏览器授权
```

之后每次：

```bash
./tools/release.sh 1.1 "新增村民日常动线"
```

它会自动：写 `VERSION` → 追加 `CHANGELOG.md` → 构建单文件版 → 打交付 zip → 提交 → 打 tag `v1.1` → 推送 → 创建 Release 并上传 zip。

也可以在 VS Code 里用任务：`终端 → 运行任务 → 发布新版本`，按提示输入版本号和说明。

### 方式 B：只用 VS Code（不装工具）

1. 改完代码，源代码管理面板写提交信息 → **Commit** → **Sync Changes**。
2. `Ctrl+Shift+P` → **Git: Create Tag** → 输入 `v1.1`。
3. `Ctrl+Shift+P` → **Git: Push Tags**。
4. 到 Releases 页面新建一条，把 `dist/Liushugou-Village-1.1.zip` 拖上去。

打包命令：

```bash
./tools/package.sh      # 产物在 dist/
```

## 四、版本号约定

`主版本.次版本`，与 `CHANGELOG.md` 的条目标题、git tag 三者保持一致：

| 场景 | 示例 |
|---|---|
| 视觉/交互有较大变化 | `1.1` → `1.2` |
| 修 bug、调参数 | `1.0` → `1.0.1` |
| 换技术路线、重构 | `1.x` → `2.0` |

`VERSION` 文件是唯一真相源，`release.sh` 会写它，`package.sh` 会读它来命名 zip。
