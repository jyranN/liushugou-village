硬约束「净增 ≤20」满足：实际是净减少。实测 −65 与设计 −52 的差额来自阴影/合批统计口径，不是新增隐藏对象。

## 三、FPS 前后

同机位（村中心 120 米环视，phi 0.9）、1280×720、像素比 1、精致档：

| 版本 | 三轮中位 FPS | 交错 A/B（各两轮） |
|---|---|---|
| v1.0 | 29.6 / 29.2 / 24.6 | 26.6 / 29.9 |
| v1.1 | 29.5 / 23.3 / 23.1 | 22.0 / 30.6 |

结论：v1.1 三角面 +13%（307 万 vs 271 万），draw call −65；无头 Edge 会热降频，同一版本两轮能差 7 FPS，**两版差异落在测量噪声里，不宣称快慢**。默认均衡档 QA 记录 54 FPS。
