# Release Notes · v1.2（2026-11-10）

v1.2 是一次内容与表现力的大版本：在 v1.1 的地形、河道、气象驱动骨架上，补齐了**生产与生活内容、季节物候、教学工具与数据可视化**四大块。全程未新增运行时依赖（`package.json` 仍只有 esbuild），单文件版保持 `file://` 双击可用、离线零外部请求。

## 一、新内容一览

### 场景内容

- **生产性空间**：6 处场院（晾晒、堆贮、农机停放），档案与落位校验齐全
- **公共核心**：村中心 5 处公共场所（含 4 处新建），成为巡游与社交动线的锚点
- **树木四种轮廓**：杨 / 柳 / 槐 / 榆按区位分配（主路杨、院落槐榆、河边柳），树段独立随机序列可复现
- **野性层植被**：山坡田边灌木 8000 丛 + 杂草 14000 丛，六路密度权重 × 斑块噪声，季节配色接时间轴
- **牲畜微动作**：牛反刍、羊侧拉、鸡双啄一停；新增看门狗 A-17（档案 198 → 199）；雨雪天按 `climate.sample` 回圈避檐
- **旱作元素**：地膜 232 条（药材黑膜 / 玉米蔬菜白膜，由作物积温驱动播种铺 / 出苗揭）、菜园木栅栏 237 m、田埂 56 条合并且宽窄随地形

### 表现与技术

- **地形材质**：草 / 土 / 石三层 PBR 混合，坡度 · 高度 · 曲率加权，近景增强远景不变
- **作物物候**：五状态（休耕 / 出苗 / 生长 / 成熟 / 留茬）由**有效积温**驱动，与岷县实际播收期对齐，当归独立形态
- **道路分层**：水泥主路 / 土巷 / 田埂三类合批为 1 个 Mesh
- **教学视图（默认全关）**：标注层（24 标签图集 + 2 m 等高线）、河谷剖面（z=−60 裁剪平面 + 分层填充 + 尺寸标注读 `RIVER` 常量），与第一人称 / 巡游互斥，关闭完全复原

### 工具与界面

- **气象数据面板**：全年气温折线 + 降水柱（8760 条实测、按屏宽降采样、Canvas 2D 自绘零依赖），游标与时间轴双向同步，重绘按需（开合 draw call 逐位相同、FPS 差 0.1）
- **P0 四件套**：风向可视化、炊烟与作息表、结构化数据卡、同机位 A/B 对比
