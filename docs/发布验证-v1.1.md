Safari 在后台标签下读到 1 FPS，**该数字不可用于性能结论**，已在 `research/baselines/v1.1/README.md`「测量边界」注明。

## 阶段 5：出包与包内核对

`./tools/package.sh` 一次产出两个包，并自动为每个包生成 `MANIFEST.txt`（文件数 / 合计体积 / 逐文件 SHA-256）与 `MANIFEST.sha256`（供 `shasum -a 256 -c` 校验）；`dist/SHA256SUMS` 记录两个 zip 的校验值。

- 交付包 `Liushugou-Village-1.1.zip`：根目录直放 `柳树沟村.html`、`使用说明.txt`、`README.md`、`CHANGELOG.md`、`VERSION`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`PROVENANCE.md`、`CITATION.cff`、`.gitattributes`、`MANIFEST.txt`、`MANIFEST.sha256`；`文档/`、`预览图/`、`源码/` 分目录。
- 全量包 `柳树沟村-项目全量-1.1.zip`：根目录为 `柳树沟村-1.1-完整工程/`，含源码、docs（**不含 `docs/软著/evidence/`**）、research（含六本台账与 `baselines/v1.1/`）、tools、vendor、8 张预览图、`.vscode` 配置。
- 两个包都**不含** `conversation-data.json`、`.git/`、`node_modules/`、`dist/` 旧包。
- 解包到另一目录后，逐文件执行 `shasum -a 256 -c MANIFEST.sha256` 全部 OK；再双击 `柳树沟村.html` 复验一次。
