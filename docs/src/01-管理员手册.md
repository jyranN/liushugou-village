# 柳树沟村 · 数字村落 管理员手册

## 一、这份手册给谁看

### 1.1 适用对象

本手册面向**系统的操作者与演示现场负责人**，回答三个问题：怎么把它打开、怎么把它讲清楚、出问题时怎么处理。

需要说明的是：本项目是一个**单机离线运行的三维演示程序**，没有账号体系、没有后台管理界面、没有多用户权限，因此这里的"管理员"不是系统运维角色，而是"设备 + 演示现场"的负责人。

### 1.2 版本与配套文件

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.1 |
| 编制日期 | 2026-11-08 |
| 对应程序 | 柳树沟村.html（单文件离线版） |
| 配套文档 | 《项目手册》《项目目录》《项目日志》 |

### 1.3 一分钟了解它是什么

柳树沟村是一个**虚构的西北村落**：甘肃定西岷县风格，14 户人家、43 位常住人口、95 棵树、16 头牲畜、14 块耕地、13 处公共设施、9 件院落物件，另有村口 5 只石墩、1 座石碾、3 处水窖，共 **170 个可以点击的对象**。整个村子的天气**不是随机生成的**，而是由岷县 2025 年全年 8760 小时的真实气象记录驱动——几点日出、哪天下雨、什么时候下雪、云有多厚，都来自真实数据。

它有三种看法：像看沙盘一样从天上俯瞰，走进村子用第一人称闲逛，或者点「巡游」让镜头按 6 个镜头的路线自动走一遍（约 32 秒）。时间可以暂停、可以拖动、可以调快慢，一天最短 20 秒、最长 6 分钟。

v1.1 的场景比 v1.0 多了一条村西小河（水磨坊临河、河滩地退到东岸、漫水桥跨河）、一座村东孤山与山腰山神庙（40 级石阶、庙前老槐），以及树下生活设施与重做的家畜。

## 二、运行环境与启动

### 2.1 硬件与系统要求

| 项目 | 最低 | 建议 |
|---|---|---|
| 操作系统 | Windows 10 / macOS 11 及以上 | 近三年系统版本 |
| 浏览器 | Chrome / Edge 100+、Safari 15+ | 最新版 Chrome 或 Edge |
| 内存 | 8 GB | 16 GB |
| 显卡 | 集成显卡（Intel Iris / Apple 核显） | 独立显卡或 Apple M 系列 |
| 硬盘 | 约 30 MB 空闲 | — |
| 网络 | **不需要** | — |

不支持手机与平板：界面按鼠标 + 键盘设计，触屏上摇杆能用，但拖拽旋转和档案卡体验不完整。

### 2.2 启动方式

**方式一：双击打开（推荐给演示现场）**

直接双击 `柳树沟村.html`。文件里已经内联了全部贴图、HDRI 环境贴图和气象数据，不需要联网，不需要本地服务器，也不依赖任何安装包。浏览器地址栏会显示 `file:///...` 开头，这是正常的。

**方式二：本地服务器打开（推荐给调试）**

```bash
cd 源码
python3 -m http.server 8099
# 浏览器访问 http://localhost:8099/index.html
```

源码版使用 ES Module，必须经 HTTP 加载；直接双击 `源码/index.html` 会被浏览器的同源策略拦住，页面停在加载遮罩上。

### 2.3 首次打开会发生什么

页面会先出现一个加载遮罩，文字是"正在生成地形与材质…"。这 3 到 6 秒里，程序在做四件事：读取内联气象数据、生成地形高度场（含村西河谷与村东山体）、生成程序化贴图（砖、瓦、土墙、树皮、草地）、构建约 20 万根实例化草叶（基础层 15 万 + 近景层 5 万）与约 4.5 万株作物。

加载完成后遮罩消失，镜头从 300 米高处缓缓落到 190 米的默认机位。**这段时间不要反复刷新**，刷新只会让生成过程重来一遍。

### 2.4 关闭与重开

直接关标签页即可，程序不写本地存储、不产生缓存文件、不联网上报。下次打开仍是默认日期（2025 年 5 月 11 日上午 10 点）和默认机位。

## 四、基本操作

### 4.1 上帝视角

默认进入的就是上帝视角，镜头绕村子中心旋转。

- **左键按住拖动**：绕村旋转，上下拖动改变俯仰角（最低接近地面，最高接近正上方）
- **滚轮 / 触控板双指**：缩放，范围约 6 米到 330 米
- **点击任意物体**：弹出档案卡，镜头同时飞向该物体
- **点击空白处**：关闭档案卡并取消高亮
- **复位按钮**：回到默认机位

### 4.2 第一人称

按 `F` 或点"第一人称"进入。视线高度 1.68 米，进入时落在当前注视点旁边。

- `W A S D` 或方向键：前后左右
- 按住左键拖动：转头
- `Shift`：加速跑（视野会轻微推近）
- `Esc`：退回上帝视角

行走有碰撞：房屋、树木、村委会、畜圈、磨坊、山神庙、石墩、石碾、水窖都会挡住去路，碰到会沿着边缘滑动，不会卡死。活动范围限制在村子与东山范围内（x、z 均为 ±240 米）；走到河边会下到河岸，过桥时脚底高度按桥面计算，不会踩进水里。

### 4.3 档案卡

170 个对象每个都有一张卡，字段随类型不同：

| 类型 | 字段 |
|---|---|
| 民居 | 门牌、用途、建筑面积、结构、屋面、建成年份、常住人口、状态 |
| 树木 | 树种、树龄、胸径、树高、冠幅、健康状况、上次修剪 |
| 家畜 | 品种、耳标号、月龄、体重、免疫记录、归属农户、健康状态 |
| 地块 | 种植作物、面积、当前生育期 |
| 公共设施 | 用途、建成年份、占地面积、结构、状态 |
| 院落物件 | 类别、用途、存放/晾晒、使用时令、材质、所属农户、状态 |
| 村口石墩 | 年代、工艺、坐高、原有只数、现存只数、保存状况、归属 |
| 石碾 | 年代、碾盘直径、碾磙、重量、用途、保存状况、归属 |
| 水窖 | 窖深、蓄水量、窖盖、用途、保存状况、归属 |

卡片右上角的 `×` 和点击画面空白处都能关闭。

### 4.4 时间与天气

底部时间条就是**一年的进度条**，从 1 月 1 日到 12 月 31 日：

- 拖动滑块：直接跳到某一天某一刻，粒度 15 分钟
- 拖动时自动暂停，**松手自动恢复播放**（原本在播放的话）
- 左侧按钮：播放 / 暂停；快捷键 `空格`
- 右侧读数：日期、时刻、天气现象、气温、云量
- 读数右侧四个按钮：晴 / 阴 / 雨 / 雪，直接跳到 2025 年 8760 条实测记录中对应的极值时刻（晴：云量 <10% 的夏季最热晴天；阴：云量 >85% 的夏季正午；雨：全年降水最大的一小时；雪：气温 <0℃ 时雪量最大的一刻）。悬停按钮可以看到日期、气温、云量和选取依据；手动拖时间轴会取消高亮。

时间条右边的四档速度决定"一天走多久"：

| 档位 | 一天 = 现实 | 一年 = 现实 | 适用场景 |
|---|---|---|---|
| 6 分 | 6 分钟 | 36.5 小时 | 慢慢看日落、拍素材 |
| 3 分（默认） | 3 分钟 | 18.2 小时 | 常规演示 |
| 1 分 | 1 分钟 | 6 小时 | 快速过一遍四季 |
| 20 秒 | 20 秒 | 2 小时 | 只看昼夜循环 |

### 4.6 自动巡游

点右下角「巡游」，镜头会按 6 个镜头自动走一遍，总长约 32 秒：

1. 村口两棵老树（低机位平视，能看到树下石墩与石碾）
2. 沿主路缓慢推进
3. 停在张宅院门口，看门楼与院墙
4. 晒场，看晾晒的当归
5. 村东孤山与山腰山神庙（庙门前）
6. 拉高俯瞰全村收尾

转场全部缓入缓出，每段底部有一行字幕。巡游期间键盘和鼠标被锁住，**按 `Esc` 或点画面任意处**即可中断；如果开始前在第一人称，会先退回上帝视角再启动。结束后按钮恢复为「巡游」，镜头停在当前位置，可以继续拖拽和缩放。

## 五、演示流程建议

### 5.1 三分钟版（展厅循环播放）

1. **0:00** 默认机位俯瞰全村，讲一句"这是甘肃岷县风格的一个虚构村落，14 户 43 人"。
2. **0:30** 点击村口第一户民居，展示档案卡：面积、结构、建成年份、常住人口。
3. **0:50** 关闭卡片，滚轮拉近到晒场，点击粮囤或晒架，讲"秋收后晾当归"。
4. **1:10** 点「巡游」，让 6 个镜头自动走一遍（约 32 秒），省去手动运镜；中途按 `Esc` 可停。
5. **1:50** 按 `F` 进第一人称，沿主路走 15 秒，让观众看到草的细节和屋檐；走到村西河边，讲水磨坊与漫水桥。
6. **2:20** 退回上帝视角，把时间条从 5 月拖到 11 月，看植被由绿转黄。
7. **2:40** 把速度调到"20 秒/天"，让观众看一次完整的日落、亮灯、星空。
8. **3:10** 收尾："所有天气都来自岷县 2025 年的真实记录。"

### 5.2 八分钟版（答辩 / 汇报）

在三分钟版基础上增加四段：

- **数据真实性**：把时间拖到 2025 年 8 月的一场雨后，指出路面变湿、雾变浓。
- **冬季**：拖到 1 月，展示积雪覆盖屋顶与路面。
- **季节物候**：连续拖 4 月→7 月→10 月，说明绿度是按积温曲线插值的，不是简单换贴图。
- **技术说明**：打开 `?qa=1` 自检面板，展示 170 个对象、8760 小时数据、0 报错。
- **地形与水文**：把镜头拉到村西河边，讲河床下切 2.2 米、水位比河床高 1.6 米、桥面只比常水位高 0.3 米（漫水桥）；再到村东，讲山体抬升 58 米、庙在 45.17 米台地上。

## 六、画面与性能调节

### 6.1 先看 FPS

顶栏右上角的数字每秒刷新一次。

| FPS | 判断 | 处理 |
|---|---|---|
| 55–60 | 流畅 | 不用管 |
| 40–55 | 可用 | 可接受，演示够用 |
| 25–40 | 偏卡 | 关后处理或降分辨率 |
| 低于 25 | 不可用 | 换机器，或按 6.4 降档 |

### 6.2 画质三档与自适应分辨率

右下角「画质」有三档，切换立即生效，选择会记在浏览器 `localStorage`（键名 `liushugou.quality`），下次打开保持：

| 档位 | 渲染像素比 | GTAO | 泛光 | 阴影贴图 |
|---|---|---|---|---|
| 流畅 | 1.0 | 关 | 关 | 1024² |
| 均衡（默认） | 1.25 | 关 | 开 | 2048² |
| 精致 | 1.5 | 开 | 开 | 3072² |

阴影贴图换尺寸时会丢掉旧贴图并重建，不会出现新旧尺寸混用。

**自适应分辨率**只在极端情况下兜底：启动 2.5 秒后开始统计，每 0.8 秒看一次平均帧率；低于 20 FPS 才在当前档位的 90% 以内降一点（每次 0.12），高于 45 FPS 再慢慢升回档位值（每次 0.07），两次调整至少间隔 1 秒。也就是说，选「均衡」就按 1.25 渲染，不会像 v1.0 那样被自适应偷偷拉到 0.62。

如果演示需要**固定清晰度**（比如录屏），在地址后加 `?fixedscale=1` 关掉自适应，或用 `?scale=1.2` 直接指定倍率。

### 6.3 调试参数

参数加在 URL 后面，用 `&` 连接，例如：
`柳树沟村.html?day=200&hour=19.5&pause=1`

| 参数 | 作用 |
|---|---|
| `?day=131&hour=10` | 指定打开时的日期与小时（day 为一年中的第几天） |
| `?pause=1` | 打开时暂停时间 |
| `?speed=0..3` | 起始速度档，0=6分、1=3分、2=1分、3=20秒 |
| `?quality=low\|mid\|high` | 临时指定画质档（不写回 `localStorage`） |
| `?ao=1` | 强制打开 GTAO（用于对比，低/中档默认关闭） |
| `?nopost=1` | 关闭全部后处理（画面会明显变平，仅用于排障） |
| `?fixedscale=1` | 关闭自适应分辨率 |
| `?scale=1.2` | 指定渲染倍率（0.5–2） |
| `?nograss=1` | 不生成草叶（排障用，画面会秃） |
| `?qa=1` | 显示自检面板（对象数、数据量、报错数） |
| `?tx=0&tz=40&r=60&phi=1.3&theta=1.57` | 指定机位，`r` 为距离、`phi` 为俯仰、`theta` 为方位 |

### 6.4 低配机器的四步降档

1. 点右下角画质条切「流畅」（关泛光、关 GTAO、阴影 1024，提升最明显）
2. 需要保留泛光就选「均衡」（只关 GTAO，阴影 2048）
3. 锁低分辨率：`?quality=low&scale=0.8&fixedscale=1`
4. 浏览器全屏 + 关闭其他标签页，独显机型确认浏览器用的是独显

## 七、常见故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 双击后一片空白，没有加载动画 | 浏览器过旧，不支持 WebGL2 | 换 Chrome / Edge 最新版 |
| 加载遮罩一直不消失，超过 30 秒 | 显卡驱动异常，或 WebGL 被禁用 | 地址栏访问 `chrome://gpu` 检查 WebGL2 是否为 Hardware accelerated；更新显卡驱动 |
| 画面全黑，但界面正常 | 显卡驱动崩溃或显存不足 | 关掉其他 3D 程序；加 `?nopost=1` 重试 |
| 画面发白发灰、对比度很低 | 关掉后处理后失去色调映射的典型表现 | 去掉 `nopost` 参数 |
| 很卡，FPS 个位数 | 集成显卡 + 高分辨率屏 | 按 6.4 降档；确认没有同时开录屏软件 |
| 天空出现一条横带 | 旧版本问题（雾带颜色与天空不一致） | 使用当前版本，已修复 |
| 时间不走 | 误触空格或暂停按钮 | 点"播放"或再按一次空格 |
| 点击物体不弹卡 | 拖动距离超过 6 像素会被判定为旋转 | 轻点，不要拖动 |
| 档案卡挡住画面 | 卡片固定在右侧 | 点空白处或按 `Esc` 关闭 |
| 中文显示成方块 | 系统缺少中文字体 | 安装宋体/黑体，或换一台机器 |

## 八、内容维护

### 8.1 修改村落数据

所有村落内容集中在 `源码/js/data.js`，都是普通 JavaScript 数组：

- `HOUSES`：14 条民居，字段含 `id / name / pos / yard / area / structure / roof / built / residents / vacant`
- `TREES`：95 条树木，含 `kind / age / dbh / height / canopy`
- `ANIMAL_LIST`：16 条牲畜
- `FIELDS`：14 块地，含 `crop / area / stage`
- `FACILITIES`：13 处设施
- `YARD_DETAILS`：9 件院落物件
- `STONES`：5 只村口石墩；`MILLSTONE`：1 座石碾；`CISTERNS`：3 处水窖
- `ALL_OBJECTS`：以上全部汇总（170 条），拾取、档案卡、自检都从这里来

改完必须重新打包（见 8.4），否则单文件版还是旧数据。编号规则见《项目目录》第十章。

### 8.2 替换气象数据

`源码/data/minxian-2025-raw.json` 是 Open-Meteo 的原始返回，结构为 `hourly` + `daily` 两组数组。替换时保持字段名不变、长度一致（`hourly.time` 必须是 8760 条，`daily.time` 365 条），否则时间引擎会读越界。

若换成别的地区，还要同步修改 `js/climate.js` 顶部的 `LAT / LON` 两个常量，否则太阳方位会对不上。

### 8.3 替换贴图与环境光

贴图放在 `源码/assets/tex/`，命名规则是 `材质名_diffuse.jpg`、`材质名_nor_gl.jpg`、`材质名_rough.jpg`；环境贴图在 `assets/hdri/field.hdr`。替换后保持文件名不变即可，打包脚本会自动内联。

### 8.4 重新打包


## 九、数据与合规

### 9.1 虚构声明

柳树沟村、14 户居民、43 位常住人口、所有门牌号、姓名、耳标号、建成年份均为**虚构**，不对应任何真实村落与个人。演示与汇报时应主动说明这一点。

### 9.2 数据来源

- **气象**：Open-Meteo 历史档案（ERA5 再分析），岷县 2025-01-01 至 2025-12-31 逐小时，字段包括温度、相对湿度、降水、云量、风速、降雪、天气代码。Open-Meteo 数据以 CC BY 4.0 提供，正式对外发布时建议在页面或说明中标注来源。
- **贴图与环境光**：Poly Haven，CC0 许可，可商用、可不署名。
- **地形、建筑、植被、作物**：本项目程序化生成或手工建模，版权归项目所有。

### 9.3 离线与隐私

程序不发起任何网络请求，不读取本地文件，不上报任何使用数据，可以在完全断网的机器上运行。

`localStorage` 只写一个键：`liushugou.quality`（画质档位，值为 `low` / `mid` / `high`），用于下次打开时保持上次选择。不写 Cookie，不存任何个人信息。清理浏览器站点数据会把它恢复成默认的「均衡」。
