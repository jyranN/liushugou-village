## 五、数据文件

`data/minxian-2025-raw.json`（467 KB）是 Open-Meteo 的原始返回。`wind_direction_10m` 一项由 `tools/fetch-wind-direction.mjs` 从**同一条查询**补取后文本级插入，其余字段与顺序未改动（脚本自带一致性校验）。

### 5.1 结构

```json
{
  "hourly": { "time": [...8760], "temperature_2m": [...], ... },
  "daily":  { "time": [...365], "sunrise": [...], "sunset": [...], ... }
}
```

### 5.2 hourly 字段

| 字段 | 单位 | 用途 |
|---|---|---|
| time | ISO 字符串 | 时间索引，2025-01-01T00:00 起逐小时 |
| temperature_2m | ℃ | 气温，决定雨/雪与体感 |
| relative_humidity_2m | % | 湿度，驱动雾浓度 |
| precipitation | mm | 降水，驱动雨强与地面湿润 |
| cloud_cover | % | 云量，驱动天空覆盖度与光照衰减 |
| weather_code | WMO 代码 | 天气现象文案 |
| wind_speed_10m | km/h | 风速，驱动旗面展开度与草、作物的摆幅 |
| wind_direction_10m | ° | 风向（气象来向，0=北 90=东），驱动旗、草、作物、雨丝、雪片的方向 |
| snowfall | cm | 降雪，驱动积雪累积 |
| is_day | 0/1 | 数据源的昼夜标记（渲染以太阳位置为准） |

### 5.3 daily 字段

`time`、`sunrise`、`sunset`、`temperature_2m_max`、`temperature_2m_min`。日出日落用于校验天文解算，不直接驱动光照。

### 8.1 截图脚本的注意事项

- 页面若是 `document.visibilityState === 'hidden'`，`requestAnimationFrame` 会停摆，导致截图超时；脚本必须先 `Page.bringToFront` 并启用焦点模拟。
- 软件渲染（SwiftShader）下首帧可能需要 30 秒以上，等待时间不要低于 45 秒。
- 必须关闭缓存（`Network.setCacheDisabled`），否则会截到旧 JS 的画面。
